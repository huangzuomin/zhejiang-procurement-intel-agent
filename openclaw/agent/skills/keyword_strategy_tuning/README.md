# keyword_strategy_tuning

Capture user feedback for future keyword, category and scoring-rule tuning.

First version records feedback conservatively and should not silently rewrite core rules.

## First-Version Rule

This skill may capture suggested keyword, category, exclusion and scoring changes as feedback records or decision-log notes. It must not silently rewrite core rules after one casual group message.

## Review Standard

- Record the user feedback, related project and proposed rule effect.
- Explain whether the change may affect many future classifications.
- Ask for explicit confirmation before applying broad rule changes.
