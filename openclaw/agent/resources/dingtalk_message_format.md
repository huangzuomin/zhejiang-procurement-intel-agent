# DingTalk Message Format

## Daily Brief Shape

```text
政采情报简报 YYYY-MM-DD

今日新增公告: <count>
值得关注机会: <count>

A 类重点跟进
1. <title>
   类别: <category>
   理由: <reason>
   风险: <risk summary>
   动作: <recommended action>

B 类值得关注
...

回复项目序号可继续追问。
```

## Single Opportunity Answer Shape

```text
结论: <A/B/C/D + one sentence>
证据: <matched evidence>
风险: <risk tags and explanation>
建议: <next step>
不确定项: <missing fields if any>
```

## Style Rules

- Keep group messages compact.
- Prefer numbered items.
- Do not paste full公告正文.
- Include URL only when available and verified in stored data.
