# Legacy System Reference

This directory contains selected reference material from the old `政采情报库` prototype.

Use it for:

- Business taxonomy seeds.
- Existing SQLite schema ideas.
- Collector/parser implementation references.
- DingTalk/notification shape inspiration.
- Puppeteer exploration references for Zhejiang procurement pages.

Do not use it as the new architecture.

Excluded from migration:

- `data/govproc.db`
- `.venv/`
- `venv/`
- `node_modules/`
- `__pycache__/`
- runtime logs
- secrets or environment files

The OpenClaw-native rewrite should follow `docs/project_spec.md` and `docs/openclaw-contract.md` first.
